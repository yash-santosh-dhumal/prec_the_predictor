# Chart Signal Lab

A lightweight web app that accepts a chart image upload (forex, crypto, metals, stocks, indices), performs image-based momentum estimation, and outputs a structured trade idea:

- Buy/Sell bias
- Confidence
- Entry, target, stop loss
- Risk/reward ratio
- Suggested timeframe
- Narrative market context

## Run locally

```bash
python3 -m http.server 4173
```

Open `http://localhost:4173`.

> This project is for educational use and does not provide financial advice.
